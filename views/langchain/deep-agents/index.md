# 简介

## 什么是Deep Agents?

[Deep Agents](https://docs.langchain.com/oss/javascript/deepagents/overview)是构建由大语言模型驱动的智能体和应用程序最简单的方式，内置任务规划、上下文管理的文件系统、子智能体生成和长期记忆等功能。你可以使用 Deep Agents 来完成任何任务，包括复杂且多步骤的任务。

## 内置功能

- `在环境中采取行动`：通过工具采取行动，读写文件，执行代码
- `连接你的数据`：在恰当的时刻加载记忆、技能和领域知识
- `管理增长的上下文`：总结历史记录并在长时间运行中卸载大型结果
- `并行任务`：委托给在隔离上下文窗口中运行的一般或专用子代理
- `保持同步`：在关键决策点暂停以获得人工批准
- `持续改进`：根据实际使用情况更新记忆、技能和提示

## 核心能力模块

- `规划能力`（Planning）
- `虚拟文件系统`（Virtual File System）
- `任务委托/子智能体`（Task Delegation/Subagents）
- `上下文管理`（Context Management）
- `代码执行`（Code Execution）
- `人工介入`（Human-in-the-loop, HITL）
- `技能包加载与管理`（Skills）

## 虚拟文件系统

- `统一工作空间`：为多步骤任务提供持久化的`草稿纸`和`成品区`
- `核心能力暴露`：通过API暴露核心能力，如文件读写、代码执行等，赋予智能体探索、消费、生产和执行的能力
- `状态声明周期管理`：通过不同的后端，实现从`临时会话记忆`到`长期知识库`的灵活数据持久化策略
- `外部系统接口`：通过`虚拟文件系统`概念，将数据库、云存储等复杂外部资源抽象为简单的文件操作，极大降低集成复杂度

## 沙盒 Sandbox

允许智能体直接访问宿主机的文件系统和执行外部脚本(shell)是极其危险的，利用[沙盒(Sandbox](https://docs.langchain.com/oss/javascript/deepagents/sandboxes)进行`安全隔离`，可以限制智能体的权限，防止其对宿主机的文件系统进行破坏。

### 核心作用

- `安全隔离`：在智能体与您的宿主机(生产服务器或本地电脑)之间建立一道屏障，防正智能体访问您的凭证、本地文件或干扰其他进程。
- `能力赋予`：在隔离的前提下，为智能体提供完整的文件系统操作工具(Is，read file，write file等)以及一个强大的execute工具，使其能够在沙盒内安全地运行任意Shell命令。
- `风险管控`：即使智能体被恶意提示词诱导(上下文注入攻击)，其破坏也被限制在沙盒内部，无法危及主机系统。
